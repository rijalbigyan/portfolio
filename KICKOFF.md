1. Create an empty folder, `cd` into it, run `git init`, and copy this starter's files in (keep the `src/` structure and `CLAUDE.md`).
2. Start Claude Code in that folder (`claude`) and paste the prompt below.
3. Fill in `src/data/*.ts` with real content when ready. Anything marked `placeholder: true` is shown with a visible badge until you remove it.
